# Vengeance SMP — Roleplay Website

GitHub Pages-ready static website for Vengeance SMP.

## Features
- 24-character roleplay directory based on the supplied roster screenshots
- Character search and status filters
- Clickable character profiles with Minecraft skin previews
- Lore, factions, PvP, economy, events and rules sections
- Responsive mobile layout
- Server IP copy buttons
- No build step or framework required

## Deploy on GitHub Pages
1. Upload every file in this folder to your repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch** and choose `main` / root.
4. Save and wait for GitHub Pages to publish.

Minecraft skin previews use Minotar URLs based on the character/player names. If a username has no public skin, the card still works and can be given a local image later.
